# Sticky Buttons

Возвращает поведение старых версий Minecraft: если зажать кнопку мыши, нажать
**F3 + T** (перезагрузка ресурсов) и отпустить мышь, кнопка остаётся зажатой —
игра продолжает копать / ставить блоки сама, как автокликер.

В 26.x это перестало работать. Мод возвращает эффект осознанно и предсказуемо:
залипание снимается повторным нажатием той же кнопки.

## Почему это перестало работать

Проверено по байткоду `MouseHandler` в 26.2 и 26.3:

1. `MouseHandler.onButton` обновляет `isLeftPressed` / `isRightPressed` только
   если **нет ни экрана, ни оверлея**:
   ```
   if (gui.screen() != null || gui.overlay() != null) → состояние кнопок не меняется
   ```
   На время перезагрузки ресурсов игра ставит `LoadingOverlay`, поэтому
   отпускание кнопки до состояния не доходит.

2. При закрытии оверлея `MouseHandler.grabMouse()` вызывает
   `KeyMapping.setAll()`, который заново читает физическое состояние клавиш через
   `InputConstants.isKeyDown`. То есть состояние привязок пересинхронизируется с
   реальным — «залипание» обнуляется.

Раньше пересинхронизации не было, и потерянное отпускание давало автоклик.
Патчить игру ради этого не нужно — эффект воспроизводится на уровне мода.

## Что делает мод

Каждый тик клиента (`ClientTickEvents.START_CLIENT_TICK`, до `handleKeybinds`):

- если открылся оверлей загрузки — запоминает, какие кнопки были зажаты;
- если оверлей закрылся — «зажимает» соответствующие привязки (`keyAttack`,
  `keyUse`, `keyPickItem`) и удерживает их;
- если игрок нажимает эту кнопку снова — залипание снимается, дальше всё как обычно;
- при выходе из мира состояние сбрасывается.

На экране появляется подсказка: «Кнопка залипла — нажмите её снова, чтобы
отпустить».

## Сборка

```bash
./gradlew build -Pmc=26.3     # → build/26.3/libs/sticky-buttons-1.0.1+26.3.jar
./gradlew build -Pmc=26.2     # → build/26.2/libs/sticky-buttons-1.0.1+26.2.jar
```

Нужен JDK 25. Версии игры и Fabric API — в `targets/<версия>.properties`.

## Проверка

```bash
verify/run.sh 26.3
```

Стенд `VerifySticky` загружает **собранный jar** через classpath клиента и
прогоняет 27 сценариев: зажатие до/после оверлея, снятие повторным нажатием,
правая и средняя кнопки, две кнопки сразу, два F3+T подряд, сброс при выходе.

## Установка

1. Fabric Loader 0.19.5+ и Fabric API соответствующей версии.
2. Положить jar для своей версии игры в `mods/`.
3. Мод клиентский — на сервер его ставить не нужно.
